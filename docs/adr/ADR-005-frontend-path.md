# ADR-005 前端路徑

- 狀態：**已由 ADR-008 取代**（2026-11-26 起以 Next.js 為宿主；本檔只保留歷史）
- 日期：2026-11-24

## 決定

凍結 `apps/web`。現用畫面以 `index2.html` 與 `js/` 為主體往下收。資料請求只經過 `js/api.js`。2026-11-26 起示範層已移除：`js/fixtures/demo.js` 與所有 fallback 刪除，沒有後端就顯示空狀態，不再掛示範橫幅。

啟動 Next.js 遷移的條件：某一個分頁需要伺服器渲染，或者這一個分頁的狀態複雜度已經超過單檔可以看懂的程度。兩個條件都還沒有出現之前，不把 `apps/web` 接上正式路由。

## 為什麼

`apps/web` 有鎖檔，但沒有取代現用頁面。同時維護兩套畫面會讓同一個數字出現兩種來源。先把現用頁面的請求和示範資料切開，遷移才有一個可以對照的行為。示範層最終於 2026-11-26 整套刪除。

## 代價

`index2.js` 仍然很大。新分頁要接在這套請求層上，不能另開一套 fetch。`apps/web` 的依賴先留在倉庫裡，不代表它已經是正式前端。

## 何時重審

第一個需要伺服器渲染的分頁出現，或單一分頁的狀態無法再放在一個檔案裡看完。重審時只遷移那個分頁，不整站重寫。
